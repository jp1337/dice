A small web app for one Discord community: members log in with Discord, a host starts a room, and
**the server rolls every die, enforces the turn order and pauses the game on every 6 while others still roll**, so the
moderator can talk instead of keeping score.

## Status

All six steps are done. Not yet verified on a live deployment: the Discord login on real devices and the Discord link preview.

| Step | | State |
| --- | --- | --- |
| 1 | Skeleton: container, database, migrations, `/healthz`, CI, image | done |
| 2 | Discord login, sessions, hosts, imprint, privacy notice, daily cleanup | done |
| 3 | Rooms and lobby over WebSocket | done |
| 4 | Game rules: turns, bonus die, 6 pauses the game | done |
| 5 | Host tools, co-hosts, test rooms, cleanup of simulated players | done |
| 6 | Animation, sound, reactions, public rooms, link preview, design | done |

Works today: Discord login with server membership check, rooms with a lobby, the full game with
bonus die and six pauses, every host tool, test rooms with simulated players, public rooms (read-only
without login), reactions, sound, light and dark theme. Proven behind nginx: 31 minutes idle WebSocket,
restart mid-game without a lost roll, 100 clients in one room ([acceptance](docs-tech/acceptance.md)).

## Quick start

```bash
git clone https://github.com/jp1337/dice.git && cd dice
cp .env.example .env          # fill in every value: docs/configuration.md
docker compose up -d
curl http://127.0.0.1:3000/healthz   # ok
```

Before the first login, register the redirect URL in the Discord Developer Portal:
[docs/deployment.md](docs/deployment.md#1-discord-application).

## Built with

| | |
| --- | --- |
| Server | Node.js 26, TypeScript, Fastify, `@fastify/websocket` |
| Web | React, Vite; every file served from the app's own domain |
| Database | PostgreSQL 19, Drizzle ORM; migrations run at start |
| Login | Discord OAuth2 only; members of one Discord server only |
| Image | `ghcr.io/jp1337/dice`, built and published by CI, runs as non-root |
