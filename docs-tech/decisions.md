# Decisions

Newest first. A decision changes by a new row, not by editing an old one.

| Date | Decision | Why |
| --- | --- | --- |
| 2026-11-24 | Dark tokens as plain custom properties, written twice; replaces `light-dark()` from the row below | `light-dark()` needs Safari 17.5; on iOS 16, also in the Discord in-app browser, every colour token would be invalid |
| 2026-11-24 | Theme before first paint by a classic external script (`public/theme-init.js`), colours by `light-dark()` | The CSP blocks inline scripts and styles; a parser-blocking script from our origin runs before `<body>` renders |
| 2026-11-24 | Sounds and preview image generated by committed scripts; WAV, not OGG | Origin and licence are the script itself; WAV needs no encoder dependency and stays under 60 KB |
| 2026-11-24 | `index.html` gets `BASE_URL` at serve time, the same HTML for every SPA path | Open Graph needs an absolute image URL; the build does not know `BASE_URL`, and the preview must not depend on the room (spec 10.2) |
| 2026-11-24 | Undo carries the `seq` of its target roll; the client may send it, a stale one is refused (`undo_stale`). Undone rolls stay in the history, struck through | Two hosts clicking at once must undo one roll, not two. Hosts see what was taken back |
| 2026-11-24 | R1 is a fixed rule; the concept's setting `sixRemovesPlayer` is dropped (operator's decision) | With `false` a gift order loses its meaning: people win several places, others none, removed players keep places |
| 2026-11-24 | WebSockets close when their session ends: logout (4001), expiry checked every ping tick (4001) | A socket must not outlive the login that opened it |
| 2026-11-24 | `state` is rendered once per audience (host, co-host, member) and version; joins and leaves reach others debounced (300 ms, at most 2 s), other changes when the room queue is idle | 100 joins with a 600-event history: 5,050 messages / 810 MB / 6.1 s before, 199 / 32 MB / 1.3 s after |
| 2026-11-24 | A room is in memory only while it has sockets; any unexpected failure rereads it from the database, a failed reread closes its sockets (1012); a deleted room closes them (4004). The cleanup skips rooms and users in use | Memory and database cannot drift apart for long, and the cleanup cannot delete under a running room |
| 2026-11-24 | WebSocket rate limit per person and room (10/s, burst 20, a connect costs one), at most 5 sockets per person and room; `PATCH /api/me` 10/min per IP | Per-connection limits multiplied with the number of tabs |
| 2026-11-24 | One validator for all free text others see (nickname, room name, six banner) | Blank fillers, foreign spaces and stacked marks passed the old regex |
| 2026-11-24 | `settingsSchema` has no `.default()`; `defaultSettings` is a literal | `update_settings` uses `settingsSchema.partial()`, and zod 4 still applies defaults inside `partial()`: every setting a message left out was reset |
| 2026-11-24 | Joining a room that is not in the lobby (running or finished) makes a spectator | Spec 4.2 names only the running game; a finished one has nothing to roll |
| 2026-11-24 | Unchanged participation, co-host or nickname writes no event | Keeps the moderation history free of no-ops |
| 2026-11-24 | `discordName` goes to hosts from `HOST_DISCORD_IDS` only, moderation history to hosts and co-hosts | Spec 4.10 says hosts; data minimisation decides the gap |
| 2026-11-24 | `POST /api/rooms` and `PATCH /api/me` check `Origin` like `/auth/logout` | Same CSRF rule for every cookie-authenticated write |
| 2026-11-24 | Messages over `MAX_CLIENT_MESSAGE_BYTES` close the socket (1009, `ws` `maxPayload`) | Never buffered or parsed; the client reconnects and gets `state` |
| 2026-11-24 | TypeScript stays on 6.0 | `typescript-eslint` 8.74 declares `typescript >=4.8.4 <6.1.0`; the Renovate PR for TypeScript 7 (#5) cannot update the lockfile. Revisit when `typescript-eslint` widens its range |
| 2026-11-24 | Deploy by pull: the infrastructure repository pins `sha-<commit>@sha256:…`, Renovate raises the pin, the operator's automation rolls out. Replaces the self-hosted runner deploy job of step 1 (#4) | A self-hosted runner attached to a public repository can be reached through fork pull requests |
| 2026-11-24 | Publish `sha-<commit>` and `latest` only after every check on `main` passed | The pin names an image that went through CI; the digest makes it immutable |
| 2026-11-24 | PostgreSQL 19 | Newest major at the start; every later major costs a dump and restore. Since 18 the data lives below `/var/lib/postgresql/<major>/`, so the volume mounts `/var/lib/postgresql` |
| 2026-11-24 | Node.js 26 | The Active LTS line |
| 2026-11-24 | `.dockerignore` is an allowlist | `.env`, the denylist, the German concept and `docs-tech/` can never reach the build context |
| 2026-11-24 | The personal-data denylist lives outside the repository: local file, CI secret | The list itself is the personal data it guards against |
